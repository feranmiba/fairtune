# FairTune Web (Frontend)

This package is reserved for the Next.js / React user interface to be implemented in Phase 2.

The frontend will consume:

- `@fairtune/shared` for shared enums, constants, and TypeScript types
- `@fairtune/validation` for client-side form validation matching backend DTO schemas
- Stellar wallet adapters (Freighter, Albedo, WalletConnect) for client-side non-custodial signing
